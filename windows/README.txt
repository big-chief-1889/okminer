okminer for Windows

Run okminer.exe from this folder. Keep all the files together.

Antivirus warning: Windows Defender and most antivirus programs flag
xmrig.exe as a "CoinMiner" threat and may delete or quarantine it, even
though it's the normal open-source XMRig miner. If okminer says the miner
is missing, open Windows Security > Virus & threat protection > Protection
history, pick the xmrig item, choose "Allow on device", then unzip again.

If Windows shows "Windows protected your PC" the first time, click
More info > Run anyway.

The Windows version is new and not well tested yet. Problems and source:
https://github.com/big-chief-1889/okminer
